Google Drive imports (izejošie rēķini)

✅ Savienojums: pievienota servisa konta atslēga ⚠️ Nav pievienota servisa konta atslēga Mape:

Ielīmējiet mapes saiti no pārlūka adreses joslas (vai tikai mapes ID).
Tiks saglabāta lokāli: ~/bkeeper/google/service-account.json. Atstājiet tukšu, ja negribat mainīt esošo atslēgu.
Kā iegūt servisa konta atslēgu?
  1. Atveriet console.cloud.google.com un izveidojiet projektu (vai izvēlieties esošo).
  2. APIs & Services → Library → sameklējiet un iespējojiet Google Drive API.
  3. IAM & Admin → Service Accounts → Create service account.
  4. Atveriet izveidoto kontu → Keys → Add key → Create new key → JSON → lejupielādējiet failu.
  5. Augšupielādējiet failu šeit un nospiediet Saglabāt — servisa konta e-pasts parādīsies augstāk.
  6. Google Drive atveriet mapi ar rēķiniem → Share → pievienojiet šo servisa konta e-pastu (ar skatītāja tiesībām pietiek).
  7. Ielīmējiet mapes saiti laukā augstāk un pārbaudiet savienojumu.
